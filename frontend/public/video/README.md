# Hero footage

`sf-flyover-*.mp4` is an aerial pass over San Francisco by Offgrideli, from Pexels
(https://www.pexels.com/video/city-of-san-francisco-14623515/), free to use under the
Pexels licence. The source clip was colour-graded to dusk and cut into a seamless
~19 s loop with ffmpeg; the poster is its first frame.

The landing page picks the 2160p file on wide high-DPI displays and the 1080p file
everywhere else, and skips both when the browser reports Save-Data.
